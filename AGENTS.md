# Deep Search

Локальный Python-бэкенд для поиска по каталогу сайтов. Проект также содержит CLI и Tkinter. Веб-фронтенд будет подключаться к `/api/v1` по localhost.

## Карта проекта

| Путь | Назначение |
| --- | --- |
| `python_deep_search/api.py` | HTTP API, проверка входных данных, жизненный цикл задач, прогресс по сайтам. |
| `python_deep_search/history.py` | SQLite-история, восстановление результатов, завершение прерванных задач после перезапуска. |
| `python_deep_search/search_engine.py` | Поиск по исходным страницам, обход ссылок, отмена и правила остановки. |
| `python_deep_search/network.py` | HTTP-сессии, cookie, лимиты, повторы, диагностика сетевых ошибок и антибот-проверок. |
| `python_deep_search/extractors.py` | Извлечение текста и ссылок, правила фильтрации и дедупликации. |
| `python_deep_search/config.py`, `python_deep_search/json-sites-examples/` | Формат каталога, конфиги сайтов и их значения по умолчанию. |
| `python_deep_search/models.py`, `python_deep_search/output.py` | Модели движка, экспорт результатов. |
| `python_deep_search/cache.py` | Кеш результатов, настройки и логи. |
| `python_deep_search/main.py`, `cli.py`, `gui.py` внутри пакета | Точки входа консоли и Tkinter. |
| `tests/` | Тесты движка, сетевого слоя, GUI и сценариев HTTP. |

## Запуск и проверка

- `python -m python_deep_search.api --port 8765` запускает API на loopback. Для отдельного фронтенда укажите его точный origin через `--frontend-origin`.
- `python -m pytest -q` запускает тесты. Тесты поиска используют подменённые ответы или локальный HTTP-сервер.
- Документация интерфейса и конфигурации находится в [README](python_deep_search/README.md).

## Изменения

- Используйте стабильные ID существующих сайтов. При добавлении сайта обновляйте каталог, а поисковые особенности задавайте в его конфиге.
- Сохраняйте совместимость полей и кодов `/api/v1`. Изменения формата проверяйте через HTTP-тесты. Машинные коды статусов и причин предназначены для интерфейса.
- При изменении логики обхода проверяйте отмену, частичные результаты, дедупликацию и лимиты. Обновляйте ключ кеша для новых параметров, влияющих на результат.
- История по умолчанию хранится в `python_deep_search/.cache/search_history.sqlite3`. Используйте отдельный файл истории для каждого одновременно запущенного экземпляра API. SQLite, кеш и временные файлы остаются локальными.
- Группируйте коммиты по смыслу. Историю изменений ведите в Git, включая исправления и тесты.
