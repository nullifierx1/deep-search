# Первый запуск веб-клиента

Бэкенд готов к интеграции по `/api/v1`. Проверены запуск API со встроенным каталогом, CORS для отдельного локального порта, валидация запроса и пустая история. Автоматические тесты покрывают поиск по локальному HTTP-сайту, прогресс, отмену, повтор по выбранным сайтам и восстановление истории после перезапуска.

## Для первой версии

- [ ] Собрать один пользовательский сценарий в браузере. Выбор сайтов из каталога, ввод запроса, редактирование путей, запуск, результаты со ссылками и совпадениями, отмена и повтор из истории. Regex и лимиты можно поместить в дополнительные настройки.
- [ ] Восстанавливать открытую задачу после перезагрузки страницы и продолжать опрос API до завершения. При `search_busy` открывать активную задачу из начала истории. При недоступности API показывать ошибку подключения и кнопку повтора.
- [ ] Отображать пустой результат, ограничения источника и отмену раздельно. Для неизвестного кода причины показывать общий текст и сохранять технический код в деталях. Частичные результаты должны оставаться доступны после отмены.
- [ ] Проверить полный сценарий из браузера на чистом запуске. Затем вручную проверить несколько источников встроенного каталога в пользовательской сети. Автотесты выполняются без внешних сайтов.

## По мере интеграции

- [ ] Если отдельные команды запуска мешают первому старту, добавить одну команду для запуска API и веб-клиента. Зафиксировать зависимости установки для чистого окружения.
- [ ] Если фронтенду нужно генерировать типы и форму настроек, добавить машинно-читаемый контракт с типами, диапазонами и значениями по умолчанию. Пока контракт описан в [README](python_deep_search/README.md).
- [ ] Если частый опрос передаёт слишком много данных, измерить размер ответов и добавить облегчённую выдачу прогресса. Текущий ответ содержит прогресс и накопленные результаты.
